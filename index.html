// ARSENAL

Auto-Enrichment

"Open a file. Everything else is automatic."

  • Classification, triage, and similarity hashing on load
  • MITRE ATT&CK mapping and IOC extraction
  • Background decompilation sweep with scoring
  • Library function identification via FLIRT

260 MCP Tools

"One prompt. 260 possibilities."

  • Decompilation, disassembly, and CFG analysis via angr
  • YARA scanning, capa matching, FLOSS string extraction
  • Symbolic execution and constraint solving
  • Binary Refinery: 200+ data transforms

Interactive Debugger

"Step through binaries with natural language."

  • 29 debug tools: step, breakpoints, watchpoints, snapshots
  • Qiling-powered emulation with Windows API stubs
  • API call tracing with argument/return capture
  • Memory search and user-defined function stubs

Web Dashboard

"See everything. Miss nothing."

  • 14-page live dashboard with CRT aesthetic
  • Interactive call graph with Cytoscape.js
  • Hex view, strings analysis, MITRE ATT&CK matrix
  • Real-time progress tracking and SSE updates

Multi-Format Support

"PE. ELF. Mach-O. .NET. Go. Rust. Shellcode."

PE ELF Mach-O .NET Go Rust VB6 Shellcode
  • Specialized parsers for each format
  • Framework-specific analysis (.NET metadata, Go symbols)
  • Automatic format detection and fallback modes

Binary Refinery

"200+ data transforms at your fingertips."

  • Decode, decrypt, decompress, and carve
  • XOR brute-force, base64, custom ciphers
  • IOC extraction and format conversion
  • Pipeline composition for complex transforms

// GET STARTED

Up and running in 5 commands

terminal
$ git clone https://github.com/JameZUK/Arkana.git
$ cd Arkana && ./run.sh --build
$ claude mcp add --scope project arkana -- ./run.sh --stdio
$ claude
> /arkana-analyse

Requires Docker and Claude Code. See the full installation guide for details.
